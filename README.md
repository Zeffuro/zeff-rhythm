# zeff-rhythm

A native four-lane rhythm game for osu!mania and StepMania `.sm` charts.

On Windows, open **Zeff Rhythm.exe** from the portable package.
Drop your Songs folder into the window to add it. **F2** picks a random chart.

**D / F / J / K** play; **Esc** pauses; **Enter** resumes; **R** retries.
**F5 / F6** adjust scroll speed. **F1** shows help; **F3** changes bindings.

Development: `cargo run -- app`, `cargo test --workspace`, `./scripts/package.ps1`.
